# Migration from the previous workflow package

## Preserve
- Task-driven decomposition and accountable ownership.
- Dynamic responsibilities rather than fixed job identities.
- Capability discovery and on-demand loading.
- Evidence-based acceptance and result-oriented delivery.
- Host permission and runtime boundaries.
- Handoff and continuation facts.

## Simplify or remove
- Rules that duplicate mature domain Skills.
- Mandatory full workflows for simple tasks.
- Fixed role rosters and arbitrary team-size limits.
- Process/test/Agent counts used as outcome proxies.
- Duplicate per-Agent project dossiers.
- Custom runtime infrastructure without a demonstrated gap.

Do not migrate every old rule. Identify the real failure it addresses, check whether host/domain tools already solve it, and retain it only when benefit is observable.
