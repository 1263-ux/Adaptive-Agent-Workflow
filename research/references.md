# Research References

These are starting points for review, not proof that this framework is implemented or validated.

- [Agent Skills specification](https://agentskills.io/specification) — portable Skill packaging and progressive disclosure.
- [DeerFlow](https://github.com/bytedance/deer-flow) — agent harness, subagents, skills and execution infrastructure.
- [DeepSeek Super-agent prototype](https://github.com/deepseek-ai/dsh-superagent-prototype) — router/worker and task execution research prototype.
- [Magentic-One](https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/magentic-one.html) — orchestration and progress monitoring.
- [OpenAI Agents SDK](https://developers.openai.com/api/docs/guides/agents) — agents, handoffs, guardrails, sessions and tracing.
- [Claude Code subagents](https://code.claude.com/docs/en/sub-agents) — host-specific delegation and context configuration.
- [Superpowers](https://github.com/obra/superpowers) — reusable software engineering skills and workflows.
- [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) — modular domain workflows and agent methods.
- [Towards a Science of Scaling Agent Systems](https://arxiv.org/html/2512.08296v3) — collaboration benefits depend on task structure and coordination cost.
