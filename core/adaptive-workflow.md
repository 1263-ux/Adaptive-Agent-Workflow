# Adaptive Workflow

Core loop: Understand → Explore → Organize → Execute → Deliver → Observe & Adapt. Steps can be skipped, revisited or parallelized; this is not a mandatory pipeline.

## Understand
Extract desired outcome, deliverables, constraints, prohibited actions, acceptance criteria, known inputs, available capabilities and unknowns. Ask only when missing information materially changes the plan or result.

## Explore
Explore methods, Skills, tools, project examples, code, documents, data and reusable work only when useful. Prefer trusted resources. Produce an actionable choice: what to use, why, dependencies, risks and validation.

## Organize
Choose direct, sequential, research-first, probe-first, parallel or hybrid work. Every delegated task needs an independent output and clear integration value. Define ownership or isolated workspaces for concurrent writes.

## Execute
Agents may discover/mount capabilities, replace methods, split/merge/pause/stop tasks, change ownership, probe uncertainty or return to exploration. Report meaningful outcomes, risks, blockers and decisions, not every micro-action.

## Deliver
Deliver actual artifacts against the goal. State what is complete, how it was checked, limitations and decisions needed. Process completion is not delivery.

## Observe and adapt
When quality misses, costs exceed expectations, methods conflict, requirements change or risks appear, identify the cause and choose the smallest effective adjustment. Do not blindly repeat failure paths or turn one-off issues into global rules.
